JĘZYK SQL - strukturalny język zapytań - służy do
tworzenia i modyfikowania baz danych oraz zarządzania
zgromadzonymi w nich informacjami
Główne cechy języka SQL:
- deklaratywność - definiujemy to co chcemy
dostać(osiągnąć)
- zbliżony do języka naturalnego - składania opeira
się na angielskich słowach kluczowych np. Create ,
Select
- Operowanie na zbiorach - instrukcje operują na
całych zestawach danych ( tablice , i relacje )
- Niezależność od platformy = uniwersalny standard
( można spotkać tak zwane dialekty tworzone przez
producentów np. Oracle czy Microsoft stosują własne
rozszerzenia)
Grupy poleceń SQL:
1. DDL ( data definition language) - definicja
struktury danych
służą do tworzenia , modyfikowania i usuwania samych
struktur baz danych ( tabel , widoków , indeksów .. )
CREATE , ALTER, DROP, TRUNCATE

2. DML ( data manipulation language) - pozwala na pracę na danych(rekordach) - dodawanie , zmiana ,
usuwanie
INSERT, DELETE, UPDATE

3.DQL ( data query language) - zapytania o dane
odpowiada za odczyt , filtrowanie , grupowania i
przetwarzanie informacji
!!!!: ) SELECT !!!!;)

4. DCL ( data control language) - kontrola dostępu do
danych - zarządzanie uprawnieniami użytkowników oraz
bezpieczeństwem dostępu do obiektów bazy danych
GRANT , REVOKE

5. TCL (transaction control language) - kontrola
transakcji
kontrolować współbieżny dostęp do bazy danych , czyli
grupowanie operacji które muszą się wykonać wspólnie
( jako całość) albo wcale
COMMIT, ROLLBACK, SAVEPOINT

interpreter zapytań SQL - zamienia polecenia języka SQL na wewnętrzne instrukcje systemu zarządzania
bazy danych
Optymalizator zapytań - analizuje zapytania i tworzy plan ich wykonania dobierając sposób odczytu i
przetwarzania danych tak by był on optymalny

w 1986 ANSI przedstawił standard języka SQL jednak każdy producent producent wprowadza swoje własne
dodatki tworząc własne dialekty języka SQL
Norma ISO/IEC 9070 która po raz ostatni zrewidowała w 2023 roku składnie języka SQL tworząc ostani
spojny standard

#zad1 Podać nazwisko studenta o numerze 5.
SELECT studenci.NAZWISKO FROM studenci WHERE studenci.NR_STUD = 5;
#zad2 Podać nazwy przedmiotów zaczynające się od litery A.
SELECT przedmioty.NAZWA_PRZEDM FROM przedmioty WHERE przedmioty.NAZWA_PRZEDM LIKE "A%";
#zad3 Podać nazwiska studentów studiujących na kierunku BUDOWA MC.
SELECT studenci.NAZWISKO FROM studenci INNER JOIN kierunki ON kierunki.NR_KIER = studenci.NR_KIER WHERE kierunki.NAZWA_KIER = "BUDOWA MC";
#zad4 Podać (w porządku alfabetycznym) nazwiska studentek, które z dowolnego przedmiotu
otrzymały ocenę > 4,5.
SELECT studenci.NAZWISKO FROM studenci INNER JOIN oceny ON oceny.NR_STUD = studenci.NR_STUD WHERE studenci.PLEC LIKE "K" && oceny.OCENA > 4.5 ORDER by studenci.nazwisko;
#zad5 Sporządzić wykaz wykładów realizowanych na kierunku BUDOWA MC.
SELECT przedmioty.NAZWA_PRZEDM FROM przedmioty INNER JOIN typy_przedmiotow ON typy_przedmiotow.KOD_TPRZEDM = przedmioty.KOD_TPRZEDM WHERE typy_przedmiotow.KOD_TPRZEDM = "WYK";
#zad6 Podać (w odwrotnej kolejności alfabetycznej) nazwiska studentów mężczyzn, którzy
studiują na kierunku ELEKTRONIKA MED lub INFORMATYKA.
SELECT studenci.NAZWISKO FROM studenci INNER JOIN kierunki on studenci.NR_KIER = kierunki.NR_KIER WHERE kierunki.NAZWA_KIER = "ELEKTRONIKA MED" || kierunki.NAZWA_KIER = "INFORMATYKA" && studenci.PLEC = "M" ORDER BY studenci.NAZWISKO DESC;
#zad7 Podać nazwy przedmiotów, z których wystawiono przynajmniej jedną ocenę = 5. Nazwa danego przedmiotu powinna się pojawić tylko raz.
SELECT DISTINCT przedmioty.NAZWA_PRZEDM FROM przedmioty INNER JOIN oceny on przedmioty.NR_PRZEDM = oceny.NR_PRZEDM WHERE oceny.OCENA = 5;
#zad8 Podać nazwy przedmiotów i nazwy ich przedmiotów nadrzędnych.
SELECT p1.NAZWA_PRZEDM as "Przedmioty", p2.NAZWA_PRZEDM as "Przedmioty nadrzędne" FROM przedmioty p1 INNER JOIN przedmioty p2 on p1.NAZWA_PRZEDM = p2.NAZWA_PRZEDM;
