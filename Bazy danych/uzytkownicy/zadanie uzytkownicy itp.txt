Zadanie 3. Analiza ocen studentów

1. Utwórz rolę:
analityk_ocen2

2. Utwórz widok:
vw_oceny_studentow2

zawierający:
- NR_STUD
- NAZWISKO
- OCENA

3. Nadaj roli prawo odczytu danych z widoku.

4. Utwórz użytkownika:
analityk2
Hasło: Analityk123!

5. Przypisz rolę użytkownikowi.


CREATE role 'analityk_ocen2';
CREATE OR REPLACE VIEW vw_oceny_studentow AS SELECT studenci.nr_stud AS "nr studenta" , nazwisko , ocena FROM oceny INNER JOIN studenci ON studenci.NR_STUD = oceny.NR_STUD;
GRANT SELECT ON vw_oceny_studentow TO 'analityk_ocen2';
CREATE USER 'analityk2'@'%' identified BY 'Analityk123!';
GRANT 'analityk_ocen2' to 'analityk2'@'%';
SET DEFAULT role analityk_ocen2 FOR 'analityk2'@'%';
